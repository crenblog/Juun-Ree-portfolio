# Design Ground Truth

The supplied `MobileTabletLanguageSelectionSolution.html` is the ground-truth visual and interaction specification. The deployed site must preserve its Quiet Editorial Index composition, existing multilingual behavior, desktop sidebar, compact mobile/tablet header, and all authored typography and spacing.

## Chosen Approach

**Reference-faithful static portfolio deployment.** The implementation will serve the supplied HTML exactly as the primary document rather than recreating its design in a different component system.

### Preservation Rules

The deployment retains the existing `Juun Ree` editorial design language, including the warm paper background, deep teal structural accents, asymmetric desktop sidebar, compact mobile/tablet chrome, and language selector behavior. The only added interaction is the already-approved compact Work preview fragment-scatter exit contained in the supplied source.

### Brand Essence

Juun Ree is a product designer portfolio for people evaluating calm, rigorous end-to-end design thinking. Its personality is **editorial**, **measured**, and **human-centered**.

### Implementation Boundary

The site will be deployed as the supplied static HTML. No redesign, component rewrite, generated asset, or visual substitution is permitted because fidelity to the supplied source overrides exploratory design work.
