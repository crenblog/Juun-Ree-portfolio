# Juun Ree

정적 포트폴리오. 빌드 없음. 이 폴더만 있으면 됩니다.

**관리 방법 (초보자용):** [docs/관리.md](docs/관리.md)

```
index.html            메인 — 대표 3개. 클릭하면 바로 열림
work.html             더보기 — 지금은 비어 있음
templates/case.html   새 프로젝트 복붙 조각
templates/media.html  폰 화면 · 영상 조각 (지금은 안 붙임)
js/i18n.js            문구 (EN/KR/JP)
js/chrome.js          내비 · 프리뷰
js/cases.js           케이스 열기
css/site.css          모양
assets/images/        커버
docs/관리.md          이 폴더를 어떻게 쓰는지
```

프로젝트를 하나 더 넣을 때는 `templates/case.html` 만 연다. 전체 HTML 문서가 아니다.

커버를 바꾸려면 `assets/images/` 안에서 같은 이름으로 넣고, `css/site.css`의 확장자만 맞춘다.
UTF-8만 사용. 한국어·일본어를 다른 인코딩으로 저장하지 말 것.
